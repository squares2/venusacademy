VENUS GYM – WHATSAPP SENDER (Chrome / Edge extension)
=====================================================
Install (one time, on the reception computer):
 1. Unzip this folder somewhere permanent (e.g. Documents\Venus_WA_Extension).
 2. Open chrome://extensions  (Edge: edge://extensions).
 3. Turn ON "Developer mode" (top-right / left in Edge).
 4. Click "Load unpacked" and select this folder.
 5. Open https://web.whatsapp.com and link the gym phone (scan the QR code).
 6. Open the Venus app → WhatsApp Sender page. The badge shows "Extension connected".

Use:
 • Press "Start sending". The extension opens each chat in the WhatsApp Web tab,
   presses Send, and waits a random pause before the next one.
 • Keep the browser open and the computer awake while it sends.
 • Do not type in the WhatsApp Web tab while it is sending.

The GitHub Pages address (https://squares2.github.io/...) is already included.
If your app runs on another address (custom domain), add it to the
"matches" list of bridge.js in manifest.json, then click "Reload" on the
extension card.
